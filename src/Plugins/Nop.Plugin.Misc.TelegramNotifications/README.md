# Telegram Notifications Plugin for nopCommerce

## Описание

Плагин для отправки уведомлений об изменении статуса заказов в Telegram.

## Возможности

- ✅ Уведомления о создании нового заказа
- ✅ Уведомления об изменении статуса заказа
- ✅ Уведомления об оплате заказа
- ✅ Уведомления об отмене заказа
- ✅ Уведомления о завершении заказа
- ✅ Гибкая настройка - можно включить/выключить каждый тип уведомлений отдельно

## Установка

1. Скопируйте папку плагина в `Plugins/Nop.Plugin.Misc.TelegramNotifications`
2. Перезапустите приложение
3. Перейдите в Admin Panel -> Configuration -> Local Plugins
4. Найдите "Telegram Notifications" и нажмите "Install"
5. Нажмите "Configure" для настройки плагина

## Настройка

1. Создайте бота в Telegram через @BotFather и получите токен
2. Получите Chat ID (можно использовать @userinfobot)
3. В настройках плагина укажите:
   - **Bot Token** - токен вашего бота
   - **Chat ID** - ID чата для отправки уведомлений
   - **Enabled** - включить/выключить плагин
   - Настройте типы уведомлений, которые хотите получать

## Формат уведомлений

Уведомления содержат следующую информацию:
- 📋 Номер заказа
- 📊 Статус заказа (текущий и предыдущий при изменении)
- 💰 Сумма заказа
- 👤 Информация о клиенте
- 📅 Дата создания заказа
- Иконки статусов для быстрой визуальной идентификации

## Требования

- nopCommerce 4.70 или выше
- .NET 8.0
- Telegram Bot Token
- Chat ID для отправки уведомлений

## Техническая информация

Плагин использует:
- Event Consumer pattern для подписки на события заказов
- Telegram Bot API для отправки сообщений
- IHttpClientFactory для HTTP-запросов
- Dependency Injection для регистрации сервисов

## Поддержка

При возникновении проблем проверьте:
- Правильность токена бота
- Правильность Chat ID
- Доступность Telegram API
- Логи приложения на наличие ошибок
