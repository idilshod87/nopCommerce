## Как получить Bot Token и Chat ID

### Получение Bot Token

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя для вашего бота (например: "My Store Order Notifications")
   - Введите username для бота (должен заканчиваться на "bot", например: "mystore_orders_bot")
4. BotFather выдаст вам токен в формате: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`
5. **Сохраните этот токен** - он понадобится для настройки плагина

### Получение Chat ID

#### Вариант 1: Личный чат
1. Найдите бота **@userinfobot** в Telegram
2. Отправьте ему любое сообщение
3. Бот ответит вам с вашим Chat ID (например: `123456789`)

#### Вариант 2: Групповой чат
1. Создайте группу в Telegram или используйте существующую
2. Добавьте вашего бота в группу (используйте username бота)
3. Отправьте сообщение в группу
4. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
   Замените `<ВАШ_ТОКЕН>` на токен от BotFather
5. Найдите в ответе поле `"chat":{"id":-1234567890}`
6. Используйте это значение ID (с минусом для групп)

#### Вариант 3: Канал
1. Создайте канал в Telegram
2. Добавьте вашего бота как администратора канала
3. Напишите сообщение в канал
4. Используйте метод getUpdates (как в варианте 2)
5. Chat ID канала будет в формате `-100123456789`

### Пример настройки в плагине

После получения токена и Chat ID:
1. Перейдите в Admin Panel → Configuration → Local Plugins
2. Найдите "Telegram Notifications"
3. Нажмите "Configure"
4. Заполните поля:
   - **Bot Token**: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`
   - **Chat ID**: `123456789` (или `-1234567890` для группы)
   - **Enabled**: ✓ (галочка)
5. Выберите типы уведомлений
6. Нажмите "Save"

### Тестирование

После настройки создайте тестовый заказ в вашем магазине. Вы должны получить уведомление в Telegram!

Пример уведомления:
```
🛒 Уведомление о заказе

📋 Номер заказа: #1001
📊 Статус: Pending
💰 Сумма заказа: $150.00
👤 Клиент: John Doe
📅 Дата создания: 28.12.2025 15:30

⏳ Заказ ожидает обработки
```
