# Руководство по использованию плагина Telegram Notifications

## Быстрый старт

### Шаг 1: Установка плагина Nop.Plugin.ExternalAuth.Telegram

Плагин уведомлений работает только в связке с плагином аутентификации через Telegram. Убедитесь что:

1. Плагин **Nop.Plugin.ExternalAuth.Telegram** установлен и настроен
2. Покупатели могут регистрироваться через Telegram
3. Bot Token настроен и бот работает

### Шаг 2: Установка плагина уведомлений

1. Перейдите в **Admin Panel → Configuration → Local Plugins**
2. Найдите **Telegram Notifications**
3. Нажмите **Install**
4. Дождитесь перезапуска приложения

### Шаг 3: Настройка

1. После установки нажмите **Configure**
2. Введите **Bot Token** - используйте тот же токен, что и в плагине аутентификации
3. Включите **Enabled**
4. Выберите типы уведомлений:
   - **Notify on Order Placed** - уведомление при создании заказа
   - **Notify on Order Status Changed** - уведомление при изменении статуса
   - **Notify on Order Paid** - уведомление при оплате
5. Нажмите **Save**

## Как это работает

### Регистрация покупателя

1. Покупатель открывает страницу регистрации на сайте
2. Выбирает вход через Telegram
3. Переходит в Telegram бот
4. Вводит код подтверждения
5. В базе данных создается запись в таблице `TelegramAuthSession`:
   - `CustomerId` - ID покупателя
   - `TelegramChatId` - ID чата покупателя с ботом
   - `StatusId` = 50 (Verified) - подтвержденная сессия

### Отправка уведомлений

1. Покупатель создает заказ на сайте
2. Плагин перехватывает событие `OrderPlacedEvent`
3. Получает `CustomerId` из заказа
4. Ищет запись в `TelegramAuthSession` с условиями:
   - `CustomerId` = ID покупателя
   - `StatusId` = 50 (Verified)
   - `TelegramChatId` не пустой
5. Если запись найдена - отправляет уведомление в `TelegramChatId` покупателя
6. Если не найдена - логирует предупреждение

## Проверка работы

### Проверка TelegramAuthSession

Выполните SQL-запрос:

```sql
SELECT 
    Id,
    CustomerId,
    TelegramChatId,
    TelegramUserId,
    PhoneNumber,
    StatusId,
    Status = CASE StatusId
        WHEN 10 THEN 'PendingStart'
        WHEN 20 THEN 'AwaitingContact'
        WHEN 30 THEN 'ContactReceived'
        WHEN 40 THEN 'CodeIssued'
        WHEN 50 THEN 'Verified'
        WHEN 60 THEN 'Expired'
    END,
    CreatedOnUtc,
    VerifiedOnUtc
FROM TelegramAuthSession
WHERE CustomerId IS NOT NULL
ORDER BY VerifiedOnUtc DESC
```

Должны быть записи со `StatusId = 50` для покупателей, зарегистрированных через Telegram.

### Проверка логов

Откройте файл логов `App_Data/Logs/nopCommerce-YYYY-MM-DD.txt` и найдите:

```
Successfully sent Telegram notification to chat 123456789
```

или

```
Customer 42 does not have Telegram Chat ID. Skipping notification for order 12345
```

## Устранение неполадок

### Уведомления не приходят

**Проблема:** Покупатель не получает уведомления

**Решения:**

1. Проверьте, что покупатель зарегистрирован через Telegram:
   ```sql
   SELECT * FROM TelegramAuthSession WHERE CustomerId = <ID покупателя>
   ```

2. Убедитесь что StatusId = 50:
   ```sql
   SELECT StatusId FROM TelegramAuthSession WHERE CustomerId = <ID покупателя>
   ```

3. Проверьте Bot Token в настройках плагина

4. Проверьте логи на ошибки Telegram API

### Ошибка "Customer does not have Telegram Chat ID"

**Причина:** У покупателя нет подтвержденной сессии в Telegram

**Решение:**
1. Покупатель должен пройти регистрацию через Telegram
2. Проверьте работу плагина Nop.Plugin.ExternalAuth.Telegram

### Telegram API возвращает ошибку 400/403

**Причина:** Неправильный Bot Token или Chat ID

**Решение:**
1. Проверьте правильность Bot Token
2. Убедитесь что бот не заблокирован
3. Проверьте что покупатель не заблокировал бота

## Безопасность

- Bot Token хранится в зашифрованном виде в базе данных
- Уведомления отправляются только покупателям с подтвержденной сессией (StatusId = 50)
- Личные данные покупателя передаются только через защищенное HTTPS соединение Telegram API
- Один покупатель = один Telegram чат (последняя подтвержденная сессия)

## FAQ

**Q: Можно ли использовать разные боты для аутентификации и уведомлений?**

A: Технически да, но не рекомендуется. Используйте один и тот же Bot Token для удобства покупателей.

**Q: Что если покупатель не регистрировался через Telegram?**

A: Уведомления не будут отправлены. В логах появится предупреждение.

**Q: Можно ли отправлять уведомления администратору?**

A: Нет, текущая версия отправляет уведомления только покупателям. Для уведомлений администратора используйте другой плагин.

**Q: Какие языки поддерживаются в уведомлениях?**

A: Используется язык магазина (ru-RU, en-US и т.д.) для статусов заказов. Текст шаблона можно изменить в коде.

**Q: Можно ли кастомизировать текст уведомлений?**

A: Да, отредактируйте метод `BuildOrderMessageAsync` в файле `TelegramNotificationService.cs`
